# CTF Challenges

This folder contains CTF challenge files designed for testing the Agentic AI Security Harness.

## Challenge Levels

### Level 1 - Beginner

Focus:
- Security awareness
- Vulnerability identification
- Evidence analysis
- Security recommendations

Example challenges:

| File | Topic | Difficulty |
|---|---|---|
| easy01_hidden_message.txt | Information Disclosure | Easy |

## Expected AI Agent Tasks

The AI security agent should:

1. Read and understand the challenge description
2. Identify the security vulnerability
3. Extract important evidence
4. Explain the security impact
5. Recommend remediation steps
6. Generate the final CTF flag
