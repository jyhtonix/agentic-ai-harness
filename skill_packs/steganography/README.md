# Steganography Skill Pack

Detect and extract hidden data from images, audio, and media files.

## Coverage
- LSB steganography detection and extraction
- Metadata and EXIF analysis
- Appended data and file carving
- Audio steganography (spectrogram, phase)
- Common encoding tricks (hidden in whitespace, polyglots)

## Verification
- Hidden message fully extracted
- Embedding technique identified
- Extraction steps documented and reproducible
