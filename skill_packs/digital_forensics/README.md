# Digital Forensics Skill Pack

Conduct systematic digital forensics analysis on disk images, memory captures, and log files.

## Coverage
- File system analysis (NTFS, ext4, FAT32)
- Memory analysis with Volatility
- Timeline reconstruction and correlation
- Browser and application artifact analysis
- Evidence handling and chain of custody

## Verification
- Findings supported by multiple artifacts
- Timeline of events reconstructed
- Chain of custody documented
